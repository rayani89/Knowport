# Knowport
Um site feito para auxiliar no desenvolvimento da língua inglesa!
 Em Knowport, você recebe uma série de tópicos construídos afim de revelar um pouco sobre diferentes áreas da comunicação do português para o inglês!
Alguns desses tópicos apresentam uma porção de contéudos como cumprimentos, ordens e pedidos, direcionamento e muitos outros! Na versão atual, o site
se concentra na apresentação de palavras relacionadas ao contéudo e uma série de perguntas que buscam trazer mais familiaridades com essas palavras.
